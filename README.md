# pairwise-rigidbody-stacking

箱子堆到第四层开始自己抖，solver 迭代次数固定，高层接触力还没收敛就进入下一帧；接触缓存按物体对存一个点，箱底四个角只解了一个；sleep 阈值按线速度判断，角速度很小时物体提前睡着又被撞醒；质量比跨三个数量级，轻箱子被重箱子挤穿；CCD 只对快速物体开启，堆叠底层的缓慢穿透没人管；物理步长跟着渲染帧走，帧率抖动时堆叠高度周期性起伏；摩擦锥用单方向近似，斜着推整摞箱子会整体滑走；多接触点求解顺序按哈希表遍历，每帧结果不同；网络同步只发位置不发角速度，客户端箱子自己转；堆叠超过一定数量后直接禁用碰撞，箱子陷进地板。gameplay/rigidbody_stacking.py 是核心，tests/test_rigidbody_stacking.py 15个红。要修的是：迭代次数按接触数自适应；接触流形保留多点；sleep 同时看线速度和角速度；质量比加钳制；CCD 覆盖堆叠底层；物理固定步长；摩擦锥多方向；求解顺序按稳定 id；同步角速度；超限改分簇而不关碰撞。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
